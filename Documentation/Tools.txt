    Tools

Tools are host programs that are assembled on the build
machine and perform some action related to the build
process of Core5.

        Install Boot File

This tool is responsible for installing the stage 2
to a disk image currently being generated by the build
system. It accepts only two arguments, the disk image
(already containing the filesystem/partition table)
and the stage 2 binary image, referred to as the source
file image internally in the source code. The tool
autodetects whether the passed-in image is a FAT12-formatted
floppy disk image, or an MBR-partitioned hard disk image
with at least one FAT32-like partition.

Based on this it employs the appropriate mechanism for
installing the stage 2 to the disk image.

For floppy disk images, it simply looks for an empty entry
slot into which it could shift the other entries in order to
free root directory entry slot 0, then space is allocated and
a FAT cluster chain is created and linked into this entry.

Time-related metadata is currently stubbed, with ambitions
for proper implementation of transfer thereof.

For hard disk images, the tool instead scans for the
lowest-addressed partition, verifies that there is a
large enough "gap" for the stage 2 to be placed there
and subsequently copies the source file into the "gap".
